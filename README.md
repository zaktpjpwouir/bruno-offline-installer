# Bruno — Free Offline Installer

![Category](https://img.shields.io/badge/API_Client-blue?style=flat-square)

## About

Bruno is a free, open-source API client for Windows, macOS, and Linux that stores API collections directly in your filesystem as plain text files. Unlike Postman or Insomnia, Bruno avoids cloud sync and stores everything locally in a readable format that works naturally with Git. Bruno's offline-first, file-system-based approach resonates with developers who want full control over their API test data.

## Common Problems & Limitations

- **Ecosystem Size** — Smaller community and fewer integrations than Postman
- **Feature Completeness** — Some Postman features not yet available in Bruno
- **Team Workflow** — Team features depend on Git workflow rather than built-in sharing
- **Learning Curve** — File-system collection model requires adjustment from cloud-first tools
